# Wiki 컨텐츠 검증 (LLM Review)

Wiki 항목(D/A/P)과 원본 회의록을 비교하여 일치성, 누락, 오류를 검증합니다.

## 사용 방법

```bash
/wiki-content-review wiki/결정/D-001.md        # 단일 파일
/wiki-content-review wiki/액션아이템/          # 폴더 전체
/wiki-content-review wiki/                    # 전체 검증
```

---

## 검증 절차

### 1단계: 파일 수집

**입력 해석**:
- 파일 경로 → 단일 파일 검증
- 폴더 경로 → 해당 폴더의 모든 D/A/P 파일 검증
- `wiki/` → 결정/액션아이템/보류 폴더의 모든 파일

**파일 목록 생성**: Glob으로 D-*.md, A-*.md, P-*.md 수집

### 2단계: 각 파일 검증

**2-1) 메타데이터 추출**
```
id, source, title, owner, status, created_date 등 frontmatter 읽기
source에서 원본 회의록 파일 경로 추출
```

**2-2) 원본 회의록 읽기**
- source 필드의 회의록 파일(들) 읽기
- 파일 없으면: ❌ "source 파일 없음" 경고

**2-3) 5가지 검증 항목 확인**

| 항목 | 확인 내용 | 점수 |
|------|---------|------|
| **일치성** | Wiki 내용이 회의록과 정확히 일치? | ✅/⚠️/❌ |
| **생성 오류** | 회의록에 없는 내용을 Wiki에 작성? | ✅/⚠️/❌ |
| **누락** | 핵심 내용(근거, 담당자, 기한 등)이 빠짐? | ✅/⚠️/❌ |
| **상태 추적** | 다중 회의 항목의 상태 변화 기록? | ✅/⚠️/❌ |
| **액션 추적** | open/blocked/on_hold 상태가 명확? | ✅/⚠️/❌ |

**세부 기준**:

**일치성**: 회의록의 해당 부분과 Wiki가 일치하는가?
- source 파일 존재 여부
- title, owner, created_date 등이 회의록과 맞는가?

**생성 오류**: 회의록에 없는 추정/외부정보/추론 포함?
- "아마도", "생각해볼 수 있음" 같은 불확실 표현
- 회의에서 나오지 않은 배경 지식

**누락**: 필수 정보가 빠졌는가?
- 결정: 근거(왜?)가 명확한가?
- 액션: 담당자, 기한, 구체적 내용이 있는가?
- 보류: 원인이 설명되어 있는가?
- 선행 조건/리소스 충돌 표시 여부

**상태 추적** (다중 회의 항목):
- source에 여러 파일이 있는가? (`→` 포함)
- "상태 변화" 섹션이 있고, 날짜/사유/타임라인이 정확한가?

**액션 추적**:
- `open`: 아직 시작 안 함? 기한 임박하지 않나?
- `blocked`: 블로킹 사유가 명시되어 있는가?
- `on_hold`: 홀드 복귀 예정일이 명확한가?
- `completed`: completed_date가 기록되어 있는가?
- `untracked`: 기한 경과가 기록되어 있는가?

**2-4) 개별 리포트 생성**

```
📄 wiki/액션아이템/A-001.md

✅ 일치성: 완벽
✅ 생성 오류: 없음
✅ 누락: 없음
✅ 상태 추적: 명확
✅ 액션 추적: 명확

점수: 5/5 ⭐⭐⭐⭐⭐
```

또는 문제가 있으면:

```
⚠️ wiki/액션아이템/A-002.md

⚠️ 일치성: 부분 일치
❌ 생성 오류: 1개
❌ 누락: 2개
⚠️ 상태 추적: 부분 추적

점수: 2/5 ⭐⭐

🔍 발견사항:
  ❌ 기한 경과: 104일 (2026-04-30 → 현재 2026-08-10)
  ⚠️ 상태 변화 섹션 불완전
```

### 3단계: 종합 리포트 생성

**정렬**: 심각 (0-1점) → 경고 (2-4점) → 완벽 (5점)

**통계**:
```
총 N개 파일 검증
- ✅ 완벽: M개
- ⚠️ 경고: K개
- ❌ 심각: L개
평균: X.X/5
```

**주요 개선점**: 패턴 찾기
```
가장 많은 문제:
1. 상태 변화 타임라인 불완전 (N개)
2. 기한 경과 미표시 (K개)
3. 리소스 충돌 미명시 (L개)
```

## 도구 사용

| 단계 | 도구 | 목적 |
|------|------|------|
| 파일 수집 | Glob | `wiki/*/D-*.md` 등 패턴 매칭 |
| 파일 읽기 | Read | Wiki/회의록 내용 읽기 |
| 검색 | Grep | 특정 내용 확인 (선택) |

**하지 말 것**:
- ❌ Wiki/Raw 파일 수정 (검증만)
- ❌ 새 파일 생성
- ❌ 추정/추론으로 내용 보충

## 핵심 규칙 (CLAUDE.md 기반)

| **F-DO-1** | 미해결 항목 방치 금지 |
| **RS-DO-1** | 리소스 충돌 명시 필수 |

## 시나리오

**새 Wiki 항목 생성 후**:
```
ingest 완료 → /wiki-content-review wiki/
          → 일치성/누락/오류 검증
          → 리포트 제시
```

**상태 업데이트 후**:
```
A-002 상태 변경 → /wiki-content-review wiki/액션아이템/A-002.md
              → 상태 변화 타임라인 검증
```

**다중 회의 항목 점검**:
```
같은 항목이 3개 회의에 걸쳐 존재
→ /wiki-content-review wiki/결정/D-003.md
→ 모든 회의 내용 반영 확인
→ 상태 변화 정확성 확인
```
