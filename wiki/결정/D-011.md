## 의사결정 요약

온보딩 프로세스 개선을 위해 **B안(입력 항목 축소)**을 채택하기로 결정. 1차는 항목 축소만 진행(7개→3개)하고, 카드 스캔 기능은 2차에서 추가하기로 함.

## 배경

온보딩 과정에서 가입 이탈율이 높은 문제를 해결하기 위해 두 가지 안이 검토됨:

**A안**: 결제 정보 입력을 가입 후 첫 사용 시로 미룸
- 장점: 가입 단계 이탈 감소
- 우려: 결제 미등록 유저 증가, 실제 매출 연결 불확실

**B안**: 필수 입력 항목 자체를 축소(7개→3개)하고 카드 스캔 추가
- 장점: 근본적인 UX 개선, 입력 복잡도 감소
- 우려: 카드 스캔 개발에 2주 소요

## 의사결정 세부사항

- **의사결정자**: 이지혜(PM)
- **최종 결정**: B안 채택
- **1차 범위**: 필수 항목 축소만 (카드 스캔 제외)
- **1차 예상 개발 기간**: 3일 (스캔 제외 시)
- **배포 목표**: 2026-07-01
- **측정 기간**: 2주 (이후 지표 검토)
- **2차 계획**: 카드 스캔 기능 추가 (개발 2주 소요)

**근거**:
- A안은 지표상 좋아 보이지만 실제 매출 연결 불확실
- B안이 근본적인 개선이므로 우선순위 높음
- 스캔 기능 제외 시 개발 일정이 단축되어 빠른 피드백 가능
