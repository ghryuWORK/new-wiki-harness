## 🎯 확립된 표준

### Wiki 적재 표준 절차

```
회의 끝남
   ↓
raw/YYYY-MM-DD-회의명.md 저장
   ↓
📖 SKILL.md 읽기 ← 항상 처음부터
   ↓
ingest (7단계 프로세스)
   ↓
Wiki 항목 생성 + 문제 감지
   ↓
(수동) git add/commit/push
```

### 핵심 원칙

1. **Raw는 불변**: 절대 수정 금지 (SSOT)
2. **Wiki는 파생**: 통째로 삭제 가능
3. **SKILL.md가 SSOT**: 매번 읽고 따르기
4. **문제점을 명시**: 숨기지 않기 (개선의 출발)
5. **다중 회의 추적**: 상태 변화 기록
